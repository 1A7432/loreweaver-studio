# Agent Notes

Decision records for humans and AI-agent lanes working this repo. Three states:

- `implemented/` — standing doctrine describing current reality, written in
  the present tense.
- `rejected/` — proposals the owner rejected. Check here before proposing a
  mechanism in the same territory; a rejection is binding until the owner
  reopens it.
- `pending/` — questions raised in review that are waiting for an owner
  verdict. Nothing here is doctrine.

Format for `implemented/` and `rejected/`: problem / decision / reason / date,
plus a "rule home" link when a module docstring owns the operative rule.
